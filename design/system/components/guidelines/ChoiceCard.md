# ChoiceCard

A radio card for a one-of-few choice where each option needs an icon and a sentence: campaign type, cart display, shipping option.

- Provide `name`, `value`, `title`, `description`, `selected`, `onSelect(value)`. Optional `icon`, `meta` (a right-aligned price) and `tag` (a pop sticker on the top edge, for the recommended option only).
- Selected state: ink border, Max Orange icon tile, filled radio.
- 2–4 cards; stack them in a column when descriptions run past one line.
