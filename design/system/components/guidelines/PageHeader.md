# PageHeader

The top of every admin page: optional back link, Bricolage title with an optional status badge, a muted subtitle, and right-aligned actions.

- Provide `title`, `subtitle` (one line of context), `actions` (at most one primary button), `backLabel` + `onBack` on detail pages, `badge` for status.
- `backHref` makes the back control a link instead of a button.
