# StorefrontPage

The shopper's desktop builder for a Tiered mix campaign, rendered by the Box Builder block inside the merchant's theme. This preview is a working prototype: add, remove and change quantities.

**Features**
- Hero: one Max sticker, Bricolage headline with the max saving in `max-strong`, one sentence, countdown (only with a real end date), and a tier ladder (10% / 15% / 25%) that shows the deal at a glance.
- Category chips and sort.
- 3-column ProductTile grid beside a sticky BoxPanel: slots, tier message, gift option, subtotal, discount, total, one CTA.
- Unlocking a tier shows a toast ("You unlocked 15% off").
- Add box to cart adds one WooCommerce line (or box plus items, per settings) with the box contents as item meta.

The store header (Northwind Pantry, a made-up shop) stands in for the merchant's theme; the builder fills the theme's content width.
