# Notice

An inline message on a soft tinted ground with a tone icon: info, success, warning, critical.

- Provide `tone`, an optional bold `title`, the message as children, an optional `action` (small buttons) and `onDismiss` for tips.
- Use for setup tips, publish confirmations, stock warnings and missing-requirement errors. Never for marketing.
- No coloured left border: the tinted ground and icon carry the tone.
